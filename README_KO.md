# GTR Partner Network V6 — 한국어 운영·검토 안내

## 웹사이트의 목적
독립 GTR 영업 파트너를 모집하는 원페이지 웹사이트. 기존 GTR Wix 제품 소개 사이트를 복제하는 것이 아닙니다. **첫 번째 CTA는 파트너 신청**, 제품 정보는 파트너가 고객에게 공유할 영업 자료입니다. 베트남어 기본, 중국어 간체, 영어 제공. 한국어 페이지 없음.

## V6 변경 내용

- **누적 판매 보상 시안**: 1–5대 10%, 6–11대 11%, 12–17대 12%, 18–23대 13%, 24–35대 14%, 36번째부터 15%. 월간 실적 목표나 초기화 없음. 화면 첫 파트너 혜택 바로 아래에 그래프와 설명 추가.
- **대량 계약 처리**: 계약 1건이 36대라도 과거 판매분을 일괄 15% 소급하는 것이 아니라, 정산된 각각의 제품이 통과한 등급대로 지급하는 시안. 예: 이전 판매 0대에서 36대 모두 $24,000 기본형을 정가에 팔아 전액 회수했다면 누적 수수료 총 $107,760 (5×10% + 6×11% + 6×12% + 6×13% + 12×14% + 1×15%) × $24,000. 판매 완료/입금 순서, 부분 입금과 여러 계약의 우선순위는 계약서에서 정해야 함.
- **D&G 운영 역할**: GTR 한국 제조사 `https://www.gtrswing.com/`, 수입·통관·관세·제품 공급 등을 담당하는 D&G `https://www.dggolfgroup.com/` 링크를 제품 파트너 신뢰 섹션과 푸터에 추가. 통관·금융 내용은 운영자 제공 정보 기반.
- **베트남 코스 강조**: 실제 현지 코스 지원은 표시하되 정확한 코스명·현재 보유 개수 미확정이므로 숫자 확답 없음.
- **비교 자료**: 사용자 제공 G Company/GTR/K Company 카드의 문구를 베트남어 페이지에 재현한 카드 디자인 추가. 중국어/영어는 번역. 원본 브로슈어에 적힌 '베트남 코스 20개'와 상대 모델 스펙·가격은 **외부 검증되지 않은 판매 홍보 문구**이므로 공개 전 업체 측 점검 권장. 경쟁사에 특정 기능이 '절대 없다'는 독립적 사실 주장으로 사용하지 않음.
- V5 기준 GTR 기본형 **$24,000**, 기본 오토티업 포함, PARK **+$1,000**, 스윙플레이트 **+$13,000**, 4K 프로젝터+PC **+$3,000**, 전체 구성 합계 $41,000, 풀패키지 **$40,000** 유지. 베트남어 원본 구성도 및 사진 유지.
- 교육 분기별(온라인 가능), 본업 병행, 출근 없음, D&G 쇼룸·상담·계약·기술 및 설치 지원.

## 출고 전 반드시 사업적으로 확정할 사안

1. **누적 판매 계단 구간의 확정**: 위 5 / 11 / 17 / 23 / 35 / 36대 구분은 현재 *제안안*이지 계약서로 확정된 규칙이 아님. 웹페이지에도 이를 표시함. 누적 판매 집계는 전액 수금된 개별 장비 기준, 과거 판매분에 소급 불가. 고객 할인이 있거나 $40,000 풀패키지, 4K/플레이트 옵션 포함 계약은 자동으로 $24,000과 같은 수익 구조로 계산하지 말고 별도 규정 필요.
2. **판매 할인 및 대형 프로젝트**: 특정 할인 거래는 고객에게 견적 확정 전에 담당자가 실제 마진 검토 후 사전 서면 합의. `15%`와 별도 가격 할인을 무제한 중복 적용하지 않도록 회계 처리 기준 명확화.
3. **기본 시공비 분담**: 우수 영업 파트너 발생 시 D&G와 사업 내부적으로 비용 조정. 협의 전 자동으로 회사 부담이라고 대외 약속하지 않음.
4. **파트너 추천 수수료(1~2%)**: 파트너 소개를 기록하는 구조는 가능하지만, 다른 파트너의 판매량에서 연속 수수료를 지급하는 방식은 베트남의 다단계 판매 규제와 연관될 수 있음. 본 V6에는 **추천인 간 자동 수익 분배를 구현하거나 홍보하지 않았음**. 현지 법률 검토 후 결정.
5. **현지 가격표시, 광고·상품 비교 진술, 세금·관세·설치비, 해외 브랜드 이름 사용**은 실제 판매·배포 이전 검토.
6. **금융·할부**는 D&G 승인 및 제휴 캐피탈 조건에 따라 개별 심사될 수 있다는 수준으로만 표현함. 회사가 보증한다고 쓰지 않음.

## 사이트에 없는 기능과 운영 전 필수 작업

**중요: 가입 신청 양식은 아직 실제로 회사에 전송되지 않습니다.** '내용 복사' 기능만 제공되며 신규 지원자는 이를 통해 자동 접수될 수 없습니다. 실제 공개 모집 전에 공식 이메일 수신 또는 수집/관리 서버(Supabase 등) + 개인정보보호 고지 + 스팸 방지 기능을 연결해야 합니다.

파트너별 소개 링크 `?ref=GTR001` 인식·신청서 입력은 데모 수준입니다. 실제로는 파트너 승인 → 고유 ID 발급 → 고객 중복 및 실적 관리 → D&G 입금과 수수료 정산을 백엔드에서 별도 구현해야 합니다. URL만으로 누가 영업권을 갖는지 확정하지 않습니다.
